# 검증 묶음

```
python tests/run_all.py
```

## 왜 가짜 모델을 쓰는가

Whisper·pyannote·BGE-M3는 수 GB짜리라 검증 때마다 돌릴 수 없고,
망이 막힌 곳에서는 아예 받을 수도 없다. 그렇다고 그 경로를 검증 없이
두면 정작 사용자 PC에서 처음 돌릴 때 터진다.

그래서 모델이 내놓는 것과 **똑같은 모양의 가짜**를 만들어 끼워 넣고,
우리 코드가 그것을 제대로 다루는지 본다. 모델 자체의 정확도는
우리가 검증할 대상이 아니다.

## 묶음

| `test_robustness.py` | 손상 파일, 인코딩, 극단 입력, 원본 변조·소실 감지, 중복 병합 |
| `test_package_and_backup.py` | 발췌 구간 정확도(오디오 마커), 해시 사슬, 백업 왕복, 동시 쓰기 |

## 여기서 잡은 실제 결함

1. 빈 구간을 건너뛰면 구간 번호가 비어 앞뒤 맥락 조회에서 구간이 빠짐
2. 두 사람이 동시에 말해도 한 명 것으로 단정 (발언을 엉뚱한 사람에게 귀속)
3. 100바이트 미만 파일을 말없이 버림 (짧은 메모·문자가 소리 없이 사라짐)
4. 카톡에 이상한 날짜가 하나만 있어도 파싱 전체가 죽음
5. 줄바꿈 없는 긴 문서가 구간 하나(12만 자)로 들어가 엑셀 셀 한도 초과
6. 차단된 법률 코멘트가 목록에서 조용히 사라짐
7. **백업을 복원하면 그 백업이 덮어써져 자료가 사라짐**
8. 법령 본문의 `<중개대상물>` 같은 꺾쇠 표기가 태그로 오인되어 삭제됨
9. 조문·판례 본문에 `<br>`이 섞이면 그 뒤 내용이 전부 잘림

## 무엇을 확인할 수 없는가

실제 모델과 실제 API가 필요한 것들:
Whisper 한국어 인식 품질, pyannote 화자 분리 정확도,
BGE-M3 의미 검색 품질, 법제처 실제 응답 형태, 윈도우 경로·인코딩·`.bat` 동작.
