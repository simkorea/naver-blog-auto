# Evidence Finder dependencies
#
#   python -m pip install -r evidence/requirements-evidence.txt
#
# NOTE: This file is intentionally ASCII-only.
# pip reads requirement files using the system locale encoding when there is
# no BOM. On a Korean Windows machine that is cp949, so any UTF-8 comment here
# crashes pip with UnicodeDecodeError before a single package is installed.
# Keep every character in this file ASCII.
#
# IMPORTANT - the torch family is NOT listed in this file on purpose.
#
# torch, torchvision, torchaudio and torchcodec have interlocking versions and
# must all come from the SAME index. Installing them from PyPI gives you a CPU
# build on Windows, and mixing sources produces a DLL mismatch that shows up as
# "The code execution cannot proceed" when Python starts.
#
# Let the setup helper handle them - it picks the CUDA build that matches your
# card (RTX 50 series needs cu128, older cards cu126):
#
#     python evidence/setup_check.py --install
#
# If something already went wrong:
#
#     python evidence/setup_check.py --repair
